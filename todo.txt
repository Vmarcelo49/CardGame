# CardGame Package Structure

## Packages

- **pkg/card**: Card-related structures, catalog, and effects
- **pkg/state**: Game state management and player data
- **pkg/ui**: User interface components (buttons, labels, input)
- **pkg/render**: Rendering logic for the duel scene
- **pkg/assets**: Asset loading (fonts, images, decks)
- **pkg/logic**: Game logic updates and card interactions  
- **pkg/game**: Main game engine and scene management

## Remaining Tasks

- Invocar um monstro da mão
- Ser restringido de atacar no primeiro turno
- Passar o turno
- Oponente passar o turno de volta
- Atacar e causar dano
- Loop verificar se a condição de vitória foi alcançada
- Exibir tela de derrota/vitória
- Repetir isso com o outro jogador
